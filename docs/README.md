# ContentX 文档中心

**ContentX：面向开发者和 AI Agent 的自托管 Headless CMS。**

当前服务端以 Go 构建；公共 API、SDK 和外部扩展的目标是保持语言中立，具体边界见 [ADR-001](./ADR-001-language-and-extension-boundary.md)。

此目录包含 ContentX 的官方现行文档。不同文档各自只维护一种事实，避免定位、状态、计划和历史记录相互冲突。

## 信息优先级

当文档之间出现冲突时，按以下规则处理：

1. REST 行为以 OpenAPI 和当前实现为准，并立即修复漂移。
2. 当前完成度与发布阻断项以 `STATUS.md` 为准。
3. 产品定位、差异化价值和对外文案以 `POSITIONING.md` 为准。
4. 产品承诺与非目标以 `PRD.md` 为准。
5. 尚未完成的工作以 `ROADMAP.md` 为准。
6. 历史变化以 `CHANGELOG.md` 和归档快照为准。

## 历史资料与验证证据

- [`archive/`](./archive/)：已经完成或被替代的方案和问题清单快照。
- [`../reports/`](../reports/)：备份恢复、端到端测试和性能基准报告。

这些文件用于追溯，不会持续更新，不能替代现行官方文档。
