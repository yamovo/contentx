# 项目状态

本文档是 ContentX 当前状态的唯一事实入口。产品范围见[产品需求](./PRD.md)，未来计划见[路线图](./ROADMAP.md)。

更新日期：2026-07-26

## 发布状态

| 项目 | 状态 |
|---|---|
| 当前发布版本 | `v1.3.0` |
| 开发分支 | 包含尚未发布的安全、稳定性、测试和 MCP 改动 |
| 当前里程碑 | 安全与稳定性收口 |
| 下一里程碑 | 多租户基础 |

## 已交付

- REST API、只读 GraphQL 和 Vue 3 管理后台
- 内容、分类、标签、评论、媒体、用户和角色
- 发布工作流、修订、定时发布、自定义内容类型和国际化
- JWT、API Token、TOTP、RBAC 和接口限流
- PostgreSQL、MySQL、SQLite、Redis 和 Docker Compose
- 备份恢复、健康检查、Prometheus 和 OpenTelemetry
- stdio 与 HTTP MCP，以及受权限控制的内容写入工具

## 进行中

- Webhook 队列、并发限制和退避策略完善
- S3 驱动的真实 SDK 与兼容服务验证
- 尚未发布改动的统一回归验证和版本收口

## 已知限制

| 范围 | 限制 |
|---|---|
| GraphQL | 仅支持只读查询 |
| S3 | 当前实现仍需真实 SDK 和兼容性验证 |
| 搜索 | 内置搜索可用；外部 Meilisearch 集成尚未达到完整生产验证 |
| 插件 | 仅支持编译期内置插件，不支持任意外部插件沙箱 |
| Webhook | 尚无完整持久化投递队列 |
| 多租户 | 尚未实现租户级数据隔离、配额和计量 |
| 商业化 | 计费、SSO、SLA 和合规能力尚未交付 |

## 发布阻断项

以下任一条件未满足时，不应创建下一正式版本：

- `make check` 未通过
- 安全修复缺少成功、拒绝或降级路径测试
- 数据库迁移无法验证
- 备份无法在隔离环境恢复
- OpenAPI 与 REST 实现不一致
- 文档将计划能力描述为已交付

## 下一步

1. 完成当前安全与稳定性里程碑的退出检查。
2. 统一验证并提交尚未发布的改动。
3. 更新变更日志并确定下一版本号。
4. 开始多租户数据模型和 Repository 隔离 PoC。
