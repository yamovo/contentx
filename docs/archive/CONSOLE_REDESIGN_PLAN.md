## 一、主流 CMS 控制台设计要点

### 1.1 各家特征

| 产品 | 控制台设计哲学 | 标志性设计 |
|---|---|---|
| **WordPress** | 功能全覆盖,列表驱动 | 仪表盘小部件(快速草稿/站点健康/活动流);列表页状态 Tabs + 批量操作 + 快速编辑;六级角色 |
| **Strapi v5** | 建模与内容分离 | Content-Type Builder 独立入口;Draft & Publish 状态条常驻编辑器顶部;RBAC 细到字段级;媒体库独立一级导航 |
| **Ghost** | 写作优先,极简 | Dashboard 聚焦会员/订阅/Newsletter 数据;编辑器沉浸式;隐藏一切非发布相关功能 |
| **Directus Studio** | 数据即内容,高可定制 | Insights 自定义仪表盘(拖拽面板);字段级权限;模块化布局,集合即导航 |
| **Payload 3.x** | 开发者友好,现代化 | Live Preview 并排预览;版本 Diff 视图;Autosave;本地-first |
| **Contentful / Sanity** | SaaS 协作流 | 全局 Command Palette(⌘K);内容预览;任务分配与评论@人;定时发布日历视图 |

### 1.2 共性趋势(2025–2026 行业共识)

1. **首屏 = 概览 + 待办**:不堆图表,先回答"今天要处理什么"(待审评论、草稿、失败任务、系统告警)
2. **⌘K 全局搜索成标配**:跳页面、搜内容、执行命令三位一体
3. **状态驱动列表**:草稿/待审/已发布/已归档做成列表页顶部 Tabs,而非下拉筛选
4. **批量操作 + 行内快捷操作**:悬停行显示快捷按钮,勾选后顶部浮出批量操作条
5. **媒体库网格化**:卡片网格 + 拖拽上传 + 右侧详情抽屉(替代跳转新页)
6. **权限可视化**:角色-权限矩阵表,一眼看清谁有什么权限
7. **暗色主题 + 紧凑/舒适密度切换**
8. **仪表盘可定制**:小部件显隐、排序(Directus/Ghost 均支持)

## 二、ContentX 控制台现状盘点(代码事实)

### 2.1 已有能力(Vue 后台 `web/src`)

- **路由 25+**:仪表盘、文章(列表/编辑器/版本历史)、页面、分类、标签、内容类型、内容条目、评论、媒体库、用户(+详情)、角色、菜单、SEO(+重定向)、数据分析、插件、主题、系统设置、操作日志、API 令牌、备份恢复、Webhook、个人资料
- **权限体系**:每路由 `permission` + `adminOnly` 守卫,菜单按权限过滤
- **文章列表**:搜索、状态/分类/排序筛选、多选、分页
- **布局**:可折叠侧栏、面包屑、主题切换、用户下拉、NProgress
- **后端配套**:REST + 只读 GraphQL + MCP、RBAC、审计、限流、备份、MinIO/S3、定时发布、乐观锁

### 2.2 原型(`landing/console.html`)现状

单文件仪表盘:统计卡、趋势图(7/30/90 天)、设备分布、最新文章/评论、热门 TOP5、系统动态;真实 API 接入(`/api/v1/analytics/*` + 登录);亮/暗主题;响应式。

### 2.3 功能对比矩阵

| 模块 | 主流标配 | ContentX 现状 | 缺口 |
|---|---|---|---|
| 仪表盘 | 待办优先、小部件可定制、趋势+来源+设备 | 统计+趋势+列表 ✅;无待办区、不可定制 | ⚠️ 待办区、部件定制 |
| 全局搜索 | ⌘K 命令面板 | 仅有顶部输入框(原型)/ 无(Vue) | ❌ Command Palette |
| 文章列表 | 状态 Tabs、批量操作条、行内快捷 | 筛选下拉、多选 ✅;无状态 Tabs、批量操作条 | ⚠️ 交互层级 |
| 编辑器 | 沉浸写作、Live Preview、Autosave、版本 Diff | 编辑器+修订历史 ✅;无预览/Diff | ⚠️ 预览与 Diff |
| 媒体库 | 网格+拖拽上传+详情抽屉 | 媒体库页 ✅(交互待查) | ⚠️ 拖拽/抽屉 |
| 用户权限 | 角色-权限矩阵、字段级 | 用户/角色页 ✅;无矩阵视图 | ⚠️ 矩阵视图 |
| 数据分析 | 趋势/来源/设备/实时在线 | 趋势/来源/设备 ✅;无实时、无导出 | ⚠️ 实时与导出 |
| 评论 | 待审队列、快捷通过/驳回 | 评论管理 ✅;原型有待审标识 | ✅ 基本齐 |
| 系统设置 | 分组表单、危险操作二次确认 | 设置/备份/令牌/Webhook ✅ | ✅ 齐 |
| 通知 | 通知中心(列表+已读) | 仅红点 | ❌ 通知中心 |
| 响应式 | 移动端抽屉导航、卡片式列表 | 原型 ✅;Vue 侧栏可折叠 | ✅ 基本齐 |

## 三、改造方案清单

> 实施目标:`landing/console.html` 原型先行(单文件、可预览、可验真);Vue 后台按同方案后续跟进。

### P0 — 导航与布局重构

| # | 事项 | 说明 |
|---|---|---|
| A1 | 导航按"工作流"重分组 | 概览(仪表盘/分析)→ 内容(文章/页面/分类标签/评论)→ 资产(媒体库)→ 站点(菜单/SEO/主题)→ 系统(用户角色/令牌/Webhook/备份/审计/设置);当前原型已分组,补齐徽标计数(待审评论/草稿数) |
| A2 | ⌘K 命令面板 | 弹层:搜文章/页面/媒体 + 跳路由 + 快捷命令(新建文章/清除缓存);前端过滤演示数据,接入后打 `/articles?search=` |
| A3 | 面包屑 + 页头操作区统一 | 每页固定:标题 + 描述 + 主操作按钮(右置) |
| A4 | 密度切换 | 舒适/紧凑两档,localStorage 记忆 |

### P0 — 仪表盘改造

| # | 事项 | 说明 |
|---|---|---|
| B1 | 待办区置顶 | 三卡:待审评论(数字+去处理)、待审文章、失败 Webhook(近 24h);数据源 `comments?status=pending`、`articles?status=review`、`webhooks logs` |
| B2 | 统计卡可点跳 | 每卡点击进对应列表页并带筛选参数 |
| B3 | 图表增强 | 趋势图加环比阴影区(上期虚线叠加);设备分布改环形图;新增"实时在线"小卡(演示用模拟数) |
| B4 | 小部件显隐 | 齿轮面板勾选显隐,localStorage 持久化 |

### P1 — 内容管理(原型内新增"文章列表"视图)

| # | 事项 | 说明 |
|---|---|---|
| C1 | 状态 Tabs | 全部/已发布/草稿/待审核/已归档,带计数徽标 |
| C2 | 批量操作条 | 勾选后顶部浮条:批量发布/归档/删除(删除二次确认) |
| C3 | 行内快捷操作 | 悬停行尾显示:编辑/预览/更多(⋮) |

| C5 | 表单校验示例 | 新建文章弹窗:标题必填/slug 格式/摘要长度,实时报错文案 |

### P1 — 媒体库视图
