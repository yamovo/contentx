# 验证报告

此目录保存特定日期、环境和 Git SHA 下的测试证据，不是现行产品规范。

| 目录 | 内容 |
|---|---|
| [`backup/`](./backup/) | 数据库备份与灾难恢复演练 |
| [`benchmarks/`](./benchmarks/) | SQLite、PostgreSQL、MySQL 性能基线与对比 |
| [`e2e/`](./e2e/) | 端到端环境和业务流程验证 |

使用报告时必须核对：

1. Git SHA 是否与当前候选版本一致。
2. 工作树是否包含未提交改动。
3. 数据库、依赖和操作系统版本是否一致。
4. 报告是否验证了当前关心的成功、失败和恢复路径。

历史 PASS 只证明报告记录的提交与环境通过，不能替代当前版本复验。当前状态见[`docs/STATUS.md`](../docs/STATUS.md)，复验方法见[`docs/SOP.md`](../docs/SOP.md)。
