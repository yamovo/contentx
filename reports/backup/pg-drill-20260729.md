## 清空与恢复

1. `docker compose stop app` 停止写入与后台任务。
2. `DROP SCHEMA public CASCADE`（级联删除 30 个对象，public 表数归零）。
3. CLI 灾难恢复（一次性容器，无 HTTP 鉴权依赖）：
   `docker compose run --rm app --restore=/app/backups/db-20260729-135743.sql`
4. 恢复耗时约 5.2s，行数快照与清空前一致：
   `articles:1 users:1 permissions:68 role_permissions:104 roles:4 site_settings:13 revisions:1 plugins:1 activity_logs:3`。
