## 失败用例详细分析

### 失败 1: `404 "返回首页" button navigates to the production login entry`

- **文件**: `e2e/smoke.spec.ts:60`
- **错误**: `Test timeout of 30000ms exceeded` — 等待 `getByRole('button', { name: '返回首页' })` 超时
- **分析**: 测试导航到 `/no-such-page` 后，404 页面未渲染出"返回首页"按钮。可能原因：
  - 404 页面组件中按钮文本或角色发生变化
  - 路由配置变更导致 `/no-such-page` 未触发 404 组件
  - 注意：测试 33（`unknown route renders 404 page`）使用 `/this-route-does-not-exist` 通过了，说明 404 页面本身正常，但本测试的 `beforeEach` 中 `mockUnmockedApiAs404` 可能干扰了页面路由
- **截图**: `smoke-404-button-failed.png`

### 失败 2: `unauthenticated access to /admin redirects to login with redirect query`

- **文件**: `e2e/smoke.spec.ts:66`
- **错误**: `expect(page).toHaveURL(expected)` 失败
  - 期望: `/\/login\?redirect=\/admin\/articles$/`
  - 实际: `http://localhost:3000/admin/articles`
- **分析**: 未认证用户访问 `/admin/articles` 后，页面未重定向到登录页，而是停留在 `/admin/articles`。可能原因：
  - 前端路由守卫逻辑变更，未认证用户不再被自动重定向
  - 由于 API mock 返回 404，路由守卫获取认证状态的行为可能受影响
  - 前端可能在等待 API 响应期间尚未完成重定向（但 5s 超时已足够）
- **截图**: `smoke-admin-redirect-failed.png`
